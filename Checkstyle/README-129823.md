# Checkstyle — LEI-129823 — Pedro Victor

O gate verifica nomes de packages Java. O padrão `^[a-z][a-z0-9]*(\.[a-z][a-z0-9]*)*$` exige que cada segmento comece com uma letra minúscula e admite depois letras minúsculas e algarismos. O [ficheiro de regras](../checkstyle-129823.xml) contém só `PackageName`. O [workflow](../.github/workflows/checkstyle-129823.yml) corre em pull requests para `master`, analisa `src` e falha perante violações. [Regra oficial PackageName](https://checkstyle.org/checks/naming/packagename.html)

## Demonstração

- [Falha com o exemplo](https://github.com/LEI-131591/Battleship2/actions/runs/42496552225) no commit `7f64372`. O Checkstyle assinala `BadPackage` em `src/main/java/BadPackage/GateProbe129823.java:1:9`.
- [Sucesso depois da correção](https://github.com/LEI-131591/Battleship2/actions/runs/42496641900) no commit `ceeacb1), após retirar a classe de demonstração.

A expressão regular garante a forma do identificador. Uma designação sintaticamente válida pode continuar pouco clara. Esta regra também não avalia se a divisão de responsabilidades por packages faz sentido.
