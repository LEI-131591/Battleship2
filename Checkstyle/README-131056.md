# Checkstyle — LEI-131056 — João Dimitry

## Convenção escolhida

Nomes dos parâmetros de métodos e construtores.

Os nomes devem começar com uma letra minúscula e podem continuar com
letras ou algarismos.

## Configuração

- Regra Checkstyle: `ParameterName`
- Expressão regular: `^[a-z][a-zA-Z0-9]*$`
- Ficheiro de configuração: `checkstyle-131056.xml`
- Workflow: `.github/workflows/checkstyle-131056.yml`
- Action: `dbelyaev/action-checkstyle@v4.5.0`

O workflow está configurado para executar em pull requests dirigidos
ao ramo `master` e falhar quando são detetadas violações da regra.

## Teste

Foi criada uma classe temporária com o parâmetro `Numero`, que não
respeitava a convenção. Depois, o parâmetro foi corrigido para
`numero` e a classe temporária foi removida.

## Limitações

O Checkstyle verifica se os nomes respeitam o padrão configurado, mas
não consegue verificar se são significativos; por exemplo, `x` cumpre
a expressão e pode ser pouco claro. A configuração usa `ParameterName`
e não verifica parâmetros de `catch` ou de expressões lambda, que têm
regras próprias.
